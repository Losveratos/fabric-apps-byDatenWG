# Fabric Apps byDatenWG

Fabric Apps (Rayfin, React) on Power BI semantic models, built for **finance and controlling**: P&L statements,
KPI cockpits, sales pipelines, variance analysis. The charts are the original Power BI custom visuals
**ChartKitchen byDatenWG** and **P&L Statement byDatenWG** (inspired by IBCS®), the data comes live per DAX from the
semantic model. Next to the apps: the semantic models and Power BI reports they use, as Fabric Git items.

Developed in public, early preview. Fabric Apps and the Rayfin CLI are in preview themselves; expect changes.
Pages for the Showcase, P&L and spike apps are generated with [**dwg cli**](https://github.com/Losveratos/dwg-cli):
one app spec, the same page as a Fabric App and as a Power BI report.

![The Showcase app: a P&L statement with the plan variance as integrated waterfall](https://raw.githubusercontent.com/Losveratos/dwg-cli/main/docs/img/app-t04b-pnl-waterfall.png)

### Demo data (`data/chartkitchen-demo/`)

CSV files for the model „ChartKitchen byDatenWG Demo“ (P&L with 5,000 accounts × 36 months, sales star with six
scenarios, KPI metadata, climate anomalies, a project plan, a P&L waterfall), built by
`merged/generate_merged_demo.py` from the inputs in `industrial/` and `sources/` (fixed seed, standard library only;
running it again gives byte-identical files). The data contract is `merged/CONTRACT.md`. To use the model, set its
parameter `DemoPfad` to the absolute path of `data/chartkitchen-demo/merged/` (with a trailing backslash) and refresh.

## Getting started

You need a Fabric capacity (F-SKU or trial; F2 throttles quickly, F8+ is comfortable) in a region where Fabric Apps is
available, the tenant settings **Fabric Apps (preview)** and **Semantic Model Execute Queries REST API**, Node.js 22,
npm 11 (`npx -y npm@11`) and, for the Showcase data, Python 3 with pandas and pyarrow plus the
[Fabric CLI](https://learn.microsoft.com/rest/api/fabric/articles/fabric-command-line-interface) (`fab`).

**1 · Data and model (Showcase).** Load the Parquet files into a lakehouse and import the Direct Lake model; the exact
commands are in [`showcase/CONTRACT.md`](showcase/CONTRACT.md) (section „Neuaufbau“):

```bash
python showcase/data/gen_showcase.py                       # optional, the Parquet files are already here
fab cp <abs path>/showcase/data/parquet/<table>.parquet "<ws>.Workspace/ZlatyLev_Showcase.Lakehouse/Files/showcase/<table>/" -f
fab table load "<ws>.Workspace/ZlatyLev_Showcase.Lakehouse/Tables/<table>" --file "<ws>.Workspace/ZlatyLev_Showcase.Lakehouse/Files/showcase/<table>" --format format=parquet --mode overwrite
DWG_SQL_HOST=<sql endpoint host> DWG_SQL_ID=<sql endpoint id> python showcase/model/gen_model.py   # point the model at your lakehouse
fab import "<ws>.Workspace/ZlatyLev Showcase.SemanticModel" -i <abs path>/showcase/ZlatyLev\ Showcase.SemanticModel -f
```

`gen_model.py` rebuilds the model skeleton; measures and formats come from `showcase/model/model.csx` via Tabular
Editor (`te script`), see the contract. Refresh the model once after the import.

**2 · App.** Put your workspace ID and the semantic model ID into `apps/datenwg-showcase/rayfin/rayfin.yml`
(`<your-workspace-id>`, `<your-semantic-model-id>`), then:

```bash
cd apps/datenwg-showcase
npx -y npm@11 install
npm run typecheck && npm test && npm run build
npx rayfin login
npx rayfin up --workspace-id <ws-id> --item-name "DatenWG Showcase" --yes --json
npx rayfin up connector apply --name showcase      # semantic model connectors: apply once ...
npx rayfin up --workspace-id <ws-id> --item-name "DatenWG Showcase" --yes --json   # ... and deploy a second time
```

Users of the app need Read and Build on the semantic model. `npm run dev` runs the app locally with Fabric sign-in.

**3 · Build your own page.** With [dwg cli](https://github.com/Losveratos/dwg-cli), pick a template, let it suggest
the fields from the model, and write the page into the app and into a Power BI report:

```bash
node dwg.mjs templates
node dwg.mjs tile add --spec my-spec.json --new-page "Revenue" --template C03 --model "<this repo>/showcase/ZlatyLev Showcase.SemanticModel" --measure Umsatz
node dwg.mjs app page --app "<this repo>/apps/datenwg-showcase" --spec my-spec.json --connector showcase
```

Learnings from building these apps (toolchain, deploy, capacity, data pitfalls): [`LEARNINGS.md`](LEARNINGS.md).
